# 采用个人、本地优先的链接解读 MVP

产品第一版限定为个人使用、浏览器扩展一键收纳公开 GitHub 仓库、X 长文和博客图文，立即生成中文解读与固定分类，并将历史保存在本地。第一版明确不做工作画像、内容适配判断、PDF、视频和登录后内容。这个范围是在云端账号体系、自动同步 X 书签和个性化推荐等替代方案之间做出的取舍，目的是用最低的开发和隐私成本验证用户是否会持续使用“收纳后快速理解与分类”这一核心闭环；模型调用由用户自行配置 API Key 承担。

## Consequences

- 不包含账号、团队协作、云端同步和 X 全量抓取。
- 不包含工作画像、个性化适配度和自动推荐判断；这些属于后续验证方向。
- 分类采用预设项目分类并由模型自动归类，同时独立保留处理状态，避免自由标签造成长期混乱。
- 后续若要跨设备、多人共享或自动批处理，需要重新评估存储和任务架构。
- 个人 API Key 让模型供应商可替换，也把费用和密钥安全责任交给用户本人。

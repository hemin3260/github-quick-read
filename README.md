# 文章链接速读

文章链接速读是一个无构建步骤的 Chromium 扩展：打开公开的 GitHub 仓库、X 长文或博客，即可生成中文解读和分类，并把结果保存在浏览器本地。

> 当前为 `v0.2.0` 测试版，用于验证“打开链接 → 摘要 → 分类 → 稍后处理”的核心闭环，适合个人使用和小范围测试。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录；升级后请在扩展管理页点击“重新加载”。
5. 打开“文章链接速读”的设置页，填写 OpenAI Chat Completions 兼容接口和 API Key；模型默认自动选择。

设置页接受完整 Endpoint，以及 OpenAI、Gemini、DeepSeek 的 Base URL，并自动补全 Chat Completions 路径。

## 使用

1. 打开公开的 GitHub 仓库、X 长文或博客文章，等待正文加载完成。
2. 点击浏览器工具栏中的“文章链接速读”。
3. 点击“生成解读”，直接查看结论和重要信息。
4. 点击“查看完整解读”进入工作台，筛选分类、修改处理状态或手动修正分类。

工作台默认按最新解读排序，每页展示 10 条。普通网页会读取当前页面已渲染的正文、标题、作者、时间及图片说明；图片像素本身不会发送给模型。

node --test tests/*.test.mjs

## 已知限制

- 只处理无需登录即可在当前页面看到的文字内容；PDF、视频、付费墙及登录后内容暂不支持。
- 部分高度动态的网站可能无法完整提取正文，X 页面需先等待长文加载完成。
- GitHub 未认证 API 有速率限制。
- API Key 存储在浏览器扩展的本地存储中，只适合个人验证。
- 模型接口必须兼容 Chat Completions 的 `choices[0].message.content` 返回格式。
- 对 `408`、`429` 和常见 `5xx` 临时错误最多自动重试 3 次。
- 尚未实现跨设备同步、批量处理、X 书签同步和个性化适配。

## 隐私说明

- GitHub 元数据和 README，或当前网页正文及图片文字说明，会发送到用户自行配置的模型 API。
- 为支持“重新生成”，提取后的正文和解读结果会保存在当前浏览器的扩展本地存储中。
- API Key 不会提交到本项目仓库。请勿在共享电脑中保存高权限 API Key。
